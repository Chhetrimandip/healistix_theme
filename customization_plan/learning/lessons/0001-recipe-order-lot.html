Healistix handoff · a five-minute lesson

One recipe, different jars.

You already know that production receives structured instructions. Now distinguish what the customer chose from the physical ingredients used to make it.

RecordQuestion it answers
Build IDWhich exact recipe?
Order numberWhich purchase?
Ingredient lotWhich physical batch of base or herb was used?

Illustrative example: two customers order the same recipe on different days. Production uses a new bag of an herb for the second order. The recipe can stay the same while the order number and ingredient lot differ.

The handoff requires one production ticket per jar. It carries the recipe and gram amounts, with fields for production to enter the base lot, each herb lot, packed-on date and packer initials. Customer free text is excluded.

Practice: an herb lot is flagged. Should every jar with the same build ID be held?

Trace the jars made with the flagged physical lot. A different recipe might contain that same lot, while the same recipe made from another lot may not. The handoff's quality-response procedure calls for holding the affected batch and informing Ryan.
