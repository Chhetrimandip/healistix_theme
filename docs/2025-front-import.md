# 2025 front mockup import

Historical initial import. The later approved combined-label pipeline and catalog consolidation supersede the temporary limitations below; see `five-flavor-jar-pipeline.md` and `catalog-consolidation.md`.

Completed 2026-09-08 using the authenticated Shopify CLI. All five images returned READY. Originals retain their existing transparency; no rembg was needed. Exports are lossless WebP with consistent portrait framing. Shopify normalizes its Files URLs to PNG; this does not mean the images have white backgrounds.
