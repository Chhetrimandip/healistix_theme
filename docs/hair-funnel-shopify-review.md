# Healistix Hair Funnel — Shopify Review

The corrected experience is deployed in the unpublished **Hair Funnel Review** Shopify theme. It uses the existing Healistix header, typography and styling. The product is **sea moss gel customized with Duals herbal powders**, for adults of all genders with hair concerns.

[Open the Shopify funnel](https://healistix.com/pages/findmyseamoss?preview_theme_id=158284939402&view=hair-routine)

## Customer journey

Hair-care campaign → landing page → eight-question hair quiz → editable profile review → personalized Find My Blend page.

The quiz asks about visible hair changes, location, onset, frequency, previous attempts, desired outcome, priorities and suitability. The location question uses visual head diagrams. There are no breakfast, smoothie or taste questions.

The result reflects the customer's answers and explains the sea moss gel base and the Duals Amla/Bhringaraj ingredient direction. It is a separate template from the existing product page. Ingredient direction is not a finalized recipe or a claim that the quiz diagnoses hair loss.

## Completed and checked

## Before live ordering

The default preview does not sell an unapproved formula. Configure the approved finished product, formula/version, price and fulfillment process, then verify cart and Shopify checkout with that product. The existing conditional purchase integration is for an approved SKU; a true bespoke formula engine still requires server-side recipe validation and order/fulfillment traceability.

The live theme has not been published or changed. Preview routes use Shopify alternate templates on the existing Find My Sea Moss page; no live page records were changed.
